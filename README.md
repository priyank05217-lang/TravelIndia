# TravelIndia

A simple tourism and travel booking website built with **HTML, CSS, and JavaScript**.

Hello there! TravelIndia is a responsive travel website designed to help visitors discover destinations across India, explore packages, and submit demo booking enquiries.

- 🌐 Built with `HTML`, `CSS`, and `JavaScript`
- 🏠 Homepage with Indian travel destinations and a hero image slider
- 🧭 Responsive navigation bar with mobile menu support
- 🔐 Login form demonstration
- 📅 Demo booking form with date and phone validation
- 🧳 Travel packages with destination search and price filtering
- 🖼️ Destination gallery and customer reviews carousel
- 🌙 Dark mode toggle
- 📍 Contact section with an embedded map
- ❓ FAQ, travel tips, offers, and travel information sections
- 📧 Contact and newsletter form demonstrations
- ⬆️ Back-to-top button

## Website Sections

### Header and Navigation

The header contains the TravelIndia logo, navigation links, dark mode toggle, login button, and a responsive mobile menu.

### Home

The homepage includes a hero banner, travel introduction, image slider controls, and a link to additional travel information.

### Book Now

Visitors can enter a destination, number of guests, phone number, arrival date, departure date, and optional services. The form calculates an estimated total and validates the submitted information.

### Services

The services section highlights Wi-Fi, hotels, food and beverages, safety guidance, payment methods, transportation, adventures, and a smoking ban.

### Packages

Visitors can browse destination packages, search by destination name, filter by price, view package details, and start a booking directly from a package card.

### Gallery

The gallery displays travel destinations and landmarks with descriptions and “See More” buttons.

### Reviews

Customer reviews are displayed in a responsive Swiper carousel with profile images, comments, and ratings.

### FAQ and Travel Tips

Frequently asked questions and practical travel tips help visitors prepare for their trip.

### About and Offers

The About section explains the TravelIndia experience, while the Offers section highlights group trips, early planning, and weekend escapes.

### Contact

The contact section includes a form and an embedded map. The form displays a confirmation message as a front-end demonstration.

### Footer and Travel Information

The footer includes company information, branch locations, quick links, contact details, social links, and policy information.

## How to Use the Project

1. Download or clone the repository.
2. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
3. Keep all required images inside the `images/` folder.
4. Open `index.html` in a modern web browser.

Example repository command:

```text
git clone https://github.com/ManthanUgemuge/TravelIndia.git
```

You can also publish the project using a static hosting service such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

## Demo Limitations

This is a front-end demonstration project:

- Booking data is stored only in the visitor’s browser using `localStorage`.
- Login is a demonstration and does not use real authentication.
- Contact and newsletter forms only display confirmation messages.
- No payment gateway or backend database is connected.
- Package prices are estimates and may change in a production system.
- The website depends on external CDN resources for some icons, fonts, and the reviews carousel.
